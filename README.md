# Rhombixtechnologies_tasks
Rhombix Technologies Cybersecurity Internship Tasks - This repository contains the implementation of assigned internship tasks. This task includes a Basic Network Sniffer built in Python that captures and analyzes live network traffic, extracts IPv4 packets, and identifies TCP, UDP, and ICMP protocols with detailed packet information.
